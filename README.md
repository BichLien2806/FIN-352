#### a. Stock return calculation
I choose VN INDEX as the benchmark to calculate the change of the stocks I bought compared to this stock, and I take the stock price between March 10, 2023 and the same day of 2025[cite: 1]. Based on this, I calculate the beta of each stock according to the formula:

$$\beta = \frac{Cov(R_s, R_m)}{Var(R_m)}$$

*Where:*  
* $R_s$ = Return of the stock  
* $R_m$ = Return of the market (VN INDEX)  
* $Cov(R_s, R_m)$ = Covariance between the stock and market returns  
* $Var(R_m)$ = Variance of market returns  

Additionally, according to NYU STEM, which updates all risk premiums across multiple countries, I took the market risk premium to be 8.35%[cite: 1]. From there, I applied the Capital Asset Pricing Model (CAPM) to calculate the expected return for each stock in my portfolio[cite: 1].

Moreover, my risky portfolio has three stocks so I rely on the formula below to calculate the standard deviation of my risky portfolio[cite: 1].

$$\sigma_p = \sqrt{w_1^2\sigma_1^2 + w_2^2\sigma_2^2 + w_3^2\sigma_3^2 + 2w_1w_2\sigma_1\sigma_2\rho_{12} + 2w_1w_3\sigma_1\sigma_3\rho_{13} + 2w_2w_3\sigma_2\sigma_3\rho_{23}}$$

*Where:*  
* $w_1, w_2, w_3$ = weight of each stock in the portfolio  
* $\sigma_1, \sigma_2, \sigma_3$ = standard deviation of each stock  
* $\rho_{12}, \rho_{13}, \rho_{23}$ = correlation coefficients between stocks
